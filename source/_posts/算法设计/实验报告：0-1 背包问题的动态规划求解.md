### 一、 问题描述与形式化描述  

1. 问题定义  

给定 $n$ 种物品和 1 个背包，其中物品 $i$ 的重量是 $w_i$，其价值为 $v_i$，背包的容量为 $C$。在选择物品 $i$ 装入背包时，只能装入全部装入或不装入（即 0-1 约束）。要求选择装入背包的物品，使得装入背包中物品的总价值最大。  

2. 整数规划数学公式 (形式化描述)  

设 $x_i$ 为决策变量，表示第 $i$ 件物品是否被选中：  

$$x_i \in \{0, 1\}, \quad i = 1, 2, \dots, n$$  

其中 $x_i=1$ 表示选择物品 $i$， $x_i=0$ 表示不选择。  

- 目标函数（最大化总价值）：  
    
    $$\max\sum_{i=1}^{n} v_i x_i$$  
    
- 约束条件（总重量不超过背包容量）：  
    
    $$\sum_{i=1}^{n} w_i x_i \leq C$$  
    

---  

### 二、 动态规划算法递推式子  

设 $dp[i][j]$ 表示在前 $i$ 件物品中进行选择，且背包容量为 $j$ 时所能获得的最大价值。  

**状态转移方程：**  

$$dp[i][j] = \begin{cases} dp[i-1][j] & \text{if } j < w_i \quad (\text{装不下，只能继承前一个状态}) \\ \max(dp[i-1][j], \quad dp[i-1][j-w_i] + v_i) & \text{if } j \ge w_i \quad (\text{装得下，在“装”与“不装”中取最大值}) \end{cases}$$  

**边界条件：**  

- $dp[0][j] = 0$ (无物品可选时价值为0)  
    
- $dp[i][0] = 0$ (容量为0时价值为0)

### 三、 算法实现 (Python)  

基于实验要求的 Python 代码实现。  


```python  
import sys  
import numpy as np  

def solve_knapsack(capacity, weights, values):  
    """  
    使用动态规划求解 0-1 背包问题  
    :param capacity: 背包容量  
    :param weights: 物品重量列表  
    :param values: 物品价值列表  
    :return: (最大价值, dp表)  
    """  
    n = len(weights)  
    # 使用 capacity + 1 是为了包含容量为 0 到 capacity 的所有情况  
    dp = np.zeros((n, capacity + 1), dtype=int)  
    
    for i in range(n):  
        for j in range(capacity + 1):  
            if i == 0:  
                # 基础情况：处理第一个物品  
                if j < weights[i]:  
                    dp[i][j] = 0  
                else:  
                    dp[i][j] = values[i]  
            else:  
                # 递推情况：处理后续物品  
                if j < weights[i]:  
                    # 装不下，继承上一行结果  
                    dp[i][j] = dp[i-1][j]  
                else:  
                    # 能装下，择优：不装 vs 装  
                    dp[i][j] = max(dp[i-1][j], dp[i-1][j-weights[i]] + values[i])  
    
    return dp[n-1][capacity], dp  

def find_selected_items(dp, weights, capacity):  
    """  
    回溯 dp 表格，找出具体选了哪些物品  
    """  
    n = len(weights)  
    selected_weights = []  
    w_left = capacity  
    
    for i in range(n - 1, -1, -1):  
        is_selected = False  
        if i == 0:  
            if w_left >= weights[i] and dp[i][w_left] == dp[i][w_left]:  
                 # 特殊判断：如果dp[0][current] > 0 则说明选了  
                 if dp[i][w_left] > 0: is_selected = True  
        else:  
            # 如果当前价值 != 上一行同容量的价值，说明选了当前物品  
            if dp[i][w_left] != dp[i-1][w_left]:  
                is_selected = True  
        
        if is_selected:  
            selected_weights.append(weights[i])  
            w_left -= weights[i]  
            
    return selected_weights  

if __name__ == "__main__":  
    # 题目给定的具体示例数据  
    C = 100  
    w = [10, 40, 55, 20]  
    v = [20, 120, 55, 100]  
    
    print(f"背包容量: {C}")  
    print(f"物品重量: {w}")  
    print(f"物品价值: {v}")  
    print("-" * 30)  

    # 求解  
    max_val, dp_table = solve_knapsack(C, w, v)  
    selected_items = find_selected_items(dp_table, w, C)  

    print(f"计算结果: 背包的最大价值为 {max_val}")  
    print(f"放入背包的物品重量分别为: {selected_items}")  
```

### 五、 算法时间复杂度分析  

1. 时间复杂度  

代码主要包含两层嵌套循环：  

- 外层循环遍历物品数量 $n$，执行 $n$ 次。  
    
- 内层循环遍历背包容量从 $0$ 到 $C$，执行 $C+1$ 次。  
    
- 循环内部的操作（比较、加法、赋值）均为常数时间操作 $O(1)$。  
    

因此，该动态规划算法的时间复杂度为：  

$$T(n) = O(n \times C)$$  

其中 $n$ 为物品数量，$C$ 为背包容量。  

2. 空间复杂度  

算法构建了一个二维数组 dp 来存储状态，行数为 $n$，列数为 $C+1$。  

因此，空间复杂度为：  

$$S(n) = O(n \times C)$$
