## 一、 实验题目  

**背包问题**：给定 $n$ 种物品和 1 个背包，其中物品 $i$ 的重量是 $w_i$，其价值为 $v_i$，背包的容量为 $C$。在选择物品 $i$ 装入背包时，**可以选择物品 $i$ 的一部分**。请问应如何选择装入背包的物品，使得装入背包中物品的总价值最大？  

**测试数据**：  

- 物品数量 $n=4$，背包容量 $C=100$  
    
- 重量 $W = \{10, 40, 55, 20\}$  
    
- 价值 $V = \{20, 120, 55, 100\}$  
    

---  

## 二、 实验内容与完成情况  

### (1) 问题的数学建模（形式化描述）  

由于允许选择物品的一部分，该问题属于**分数背包问题**（Fractional Knapsack Problem）。设 $x_i$ 为第 $i$ 个物品装入背包的比例，则问题的线性规划模型如下：  

- **决策变量**：$0 \le x_i \le 1, \quad i = 1, 2, \dots, n$  
    
- 目标函数（最大化总价值）：  
    
    $$\max\sum_{i=1}^{n} v_i x_i$$  
    
- 约束条件（总重量不超过容量）：  
    
    $$\sum_{i=1}^{n} w_i x_i \le C$$  
    

### (2) 贪心算法的贪心策略  

对于分数背包问题，最佳的贪心策略是**优先选择单位重量价值（Value per Weight）最高的物品**。  

**具体步骤：**  

1. **计算密度**：对于每个物品 $i$，计算其价值密度 $r_i = \frac{v_i}{w_i}$。  
    
2. **排序**：将所有物品按照 $r_i$ 从大到小进行降序排列。  
    
3. **贪心选择**：依次考察排序后的物品：  
    
    - 若当前背包剩余容量足以装下该物品全部，则全选（$x_i=1$）。  
        
    - 若剩余容量不足，则将背包装满为止（$x_i = \frac{\text{剩余容量}}{w_i}$），算法结束。  
        

### (3) 算法实现与测试  

基于 Python 语言实现上述贪心算法，核心代码如下（完整代码见附录）：  

Python  

```  

# 核心逻辑片段  
items.sort(key=lambda x: x[1] / x[0], reverse=True) # 按性价比排序  

for w, v, i in items:  
    if current_capacity >= w:  
        # 全部装入  
        current_capacity -= w  
        max_value += v  
    else:  
        # 装入部分，填满背包  
        max_value += v * (current_capacity / w)  
        current_capacity = 0  
        break  
```

### (4) 时间复杂度分析  

算法的主要时间开销在排序步骤。  

1. **计算密度**：遍历 $n$ 个物品，复杂度 $O(n)$。  
    
2. **排序**：使用高效排序算法（如归并排序或快速排序）对 $n$ 个物品按密度排序，复杂度 $O(n \log n)$。  
    
3. **贪心遍历**：排序后只需遍历一次物品列表，复杂度 $O(n)$。  
    

综上，算法的总时间复杂度由排序决定，为 **$O(n \log n)$**。  

### (5) 贪心算法最优性证明  

要证明贪心算法能获得全局最优解，需证明该问题具有**贪心选择性质**和**最优子结构性质**。  

**1. 贪心选择性质 (Greedy Choice Property)**  

- **命题**：存在一个全局最优解，包含单位价值最高的物品（尽可能多地包含）。  
    
- **证明**：假设有一个最优解 $S$，它没有包含当前单位价值最高的物品 $i$ 的最大可能量，而是包含了一些单位价值较低的物品 $j$ ($v_i/w_i > v_j/w_j$)。我们可以用物品 $i$ 替换掉物品 $j$ 中等量的重量。由于物品 $i$ 的单位价值更高，替换后的总价值会增加。这与 $S$ 是最优解矛盾。因此，最优解一定优先包含单位价值最高的物品。  
    

**2. 最优子结构 (Optimal Substructure)**  

- **命题**：一个问题的最优解包含了其子问题的最优解。  
    
- **证明**：当我们决定了装入物品 $i$ 的数量 $x_i$ 后，原问题就转化为：在剩余容量 $C - x_i w_i$ 下，如何从剩余物品中选择以获得最大价值。如果在剩余容量下的选择不是最优的，那么将其替换为最优选择，原问题的总价值也会随之增加。因此，每一步贪心选择后的子问题也必须取最优解，才能保证全局最优。  
    

**结论**：由于分数背包问题满足上述两个性质，因此贪心算法可以获得全局最优解。  

## 附录：完整代码  

```python  
def solve(capacity, weights, values, ids):  
    """  
    分数背包问题的贪心算法实现  
    参数:  
    capacity -- 背包容量  
    weights  -- 重量数组  
    values   -- 价值数组  
    ids      -- 编号数组  
    """  
    max_value = 0.0  
    chosen_items = []  
    current_capacity = capacity  

    items = list(zip(weights, values, ids))  

    items.sort(key=lambda x: x[1] / x[0], reverse=True)  

    # 2. 贪心遍历  
    for w, v, i in items:  
        if current_capacity <= 0:  
            break  
            
        if current_capacity >= w:  
            current_capacity -= w  
            max_value += v  
            chosen_items.append((i, float(w))) # 记录放入了全部重量  
        else:  
            fraction = current_capacity / w     # 计算比例  
            added_value = v * fraction          # 计算这一部分的价值  
            
            max_value += added_value  
            chosen_items.append((i, current_capacity)) # 记录放入了剩余的所有空间  
            current_capacity = 0 # 背包已满  
            break  

    return max_value, chosen_items  

if __name__ == "__main__":  
    # 题目给定数据  
    C = 100  
    w_arr = [10, 40, 55, 20]  
    v_arr = [20, 120, 55, 100]  
    id_arr = [1, 2, 3, 4]  

    print(f"背包总容量: {C}")  
    print(f"原始数据 - 重量: {w_arr}, 价值: {v_arr}")  
    print("-" * 30)  

    total_val, details = solve(C, w_arr, v_arr, id_arr)  

    # 输出结果  
    print(f"计算得出的最大总价值: {total_val}")  
    print("详细装包方案:")  
    # 按 ID 排序输出，方便查看，虽然贪心选择顺序不是按ID来的  
    details.sort(key=lambda x: x[0])  
    for item_id, weight_taken in details:  
        print(f"物品 {item_id}: 放入重量 {weight_taken:.2f}")  
```
