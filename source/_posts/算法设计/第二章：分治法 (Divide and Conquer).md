## 一、 核心范式  

### 1. 三步曲  
* **分解 (Divide)**：将原问题分解为若干个**规模较小、相互独立、形式相同**的子问题。  
* **解决 (Conquer)**：若子问题规模足够小则直接求解，否则**递归求解**。  
* **合并 (Combine)**：将子问题的解**合并**为原问题的解。  

### 2. 通用复杂度模型（主定理 $k$ 版）  
$$  
T(n) = aT(n/b) + c \cdot n^k  
$$  
* $a$：子问题个数  
* $b$：规模缩小倍数  
* $k$：**合并步骤**的时间复杂度指数（即非递归部分为 $O(n^k)$）  

---  

## 二、 基础经典算法（主定理直接应用）  

### 1. 二分搜索 (Binary Search)  
* **逻辑**：在有序数组中，每次比较后排除一半元素。  
* **方程**：$T(n) = T(n/2) + O(1)$  
* **参数**：$a=1, b=2, k=0$  
* **分析**：$a = b^k$ ($1 = 2^0$)，属**情况2**  
* **结论**：$O(\log n)$  

### 2. 大整数乘法 (Large Integer Multiplication)  
* **朴素分治**：$T(n) = 4T(n/2) + O(n) \Rightarrow O(n^2)$  
* **优化分治**：利用代数变换将乘法次数降至**3次**  
    * **方程**：$T(n) = 3T(n/2) + O(n)$  
    * **参数**：$a=3, b=2, k=1$  
    * **分析**：$a > b^k$ ($3 > 2$)，属**情况1**  
    * **结论**：$O(n^{\log_2 3}) \approx O(n^{1.585})$  

### 3. Strassen 矩阵乘法  
* **朴素分治**：$T(n) = 8T(n/2) + O(n^2) \Rightarrow O(n^3)$  
* **Strassen 优化**：通过线性组合将乘法次数降至**7次**  
    * **方程**：$T(n) = 7T(n/2) + O(n^2)$  
    * **参数**：$a=7, b=2, k=2$  
    * **分析**：$a > b^k$ ($7 > 4$)，属**情况1**  
    * **结论**：$O(n^{\log_2 7}) \approx O(n^{2.81})$  

### 4. 循环赛日程表 (Round Robin Schedule)  
* **核心逻辑**：  
    * 左上角：递归求解的子问题  
    * 右上角：左上角元素 $+ n/2$  
    * 左下角：右上角的对角线镜像  
    * 右下角：左上角的对角线镜像  
* **复杂度**：时间 $O(n \log n)$，空间 $O(n^2)$

## 三、 排序算法（重点对比）  

### 1. 归并排序 (Merge Sort)  
* **逻辑**：递归拆分 → 有序合并（线性扫描）  
* **方程**：$T(n) = 2T(n/2) + O(n)$  
* **分析**：$a=2, b=2, k=1 \Rightarrow a = b^k$，属**情况2**  
* **结论**：$O(n \log n)$  
* **特点**：**稳定**排序，空间复杂度 $O(n)$（非就地）  

### 2. 快速排序 (Quick Sort)  
* **逻辑**：选择基准 → 划分分区 → 递归排序  
* **最好/平均情况**：$T(n) = 2T(n/2) + O(n) \Rightarrow O(n \log n)$  
* **最坏情况**：$T(n) = T(n-1) + O(n) \Rightarrow O(n^2)$（如输入已有序）  
* **特点**：**不稳定**，平均性能快，**就地**排序（栈空间 $O(\log n)$）

## 四、 进阶难点（理论证明考点）  

### 1. 线性时间选择：BFPRT 算法  
* **问题**：在无序数组中找第 $k$ 小的数  
* **对比**：  
    * **随机快选**：期望 $O(n)$，最坏 $O(n^2)$  
    * **BFPRT**：**确定性 $O(n)$**  

#### BFPRT 算法步骤（必背）  
1. **分组**：每5个元素一组  
2. **组内排序**：找出每组中位数  
3. **MoM**：递归找出“中位数的中位数”作为基准  
4. **划分**：用基准进行划分  

#### 时间复杂度证明（核心）  
* **递归方程**：$T(n) \le T(n/5) + T(7n/10) + O(n)$  
    * $T(n/5)$：找 MoM 的代价  
    * $T(7n/10)$：处理最坏子问题的代价  
* **分析**：系数和 $1/5 + 7/10 = 0.9 < 1$，形成收敛几何级数  
* **结论**：$T(n) = O(n)$  

### 2. 最接近点对 (Closest Pair of Points)  
* **问题**：二维平面 $n$ 个点，找距离最近的一对  
* **方程**：$T(n) = 2T(n/2) + O(n)$  
* **复杂度**：$O(n \log n)$  

#### 合并步骤的优化证明（鸽巢原理）  
1. **窄带筛选**：只考虑距离分割线水平距离 $< \delta$ 的点  
2. **排序**：将窄带内点按 $Y$ 坐标排序（预排序优化）  
3. **6点定理**：  
    * 对于任意点 $p$，只需检查其后**6个点**  
    * **证明**：在 $\delta \times 2\delta$ 矩形内，若超过6个点则必有两点距离 $< \delta$，与 $\delta$ 定义矛盾  
    * 保证了合并步骤是 $O(n)$ 而非 $O(n^2)$

## 五、 灵活应用（面试级题目）  

### 1. 两个等长升序数组的中位数  
* **思路**：比较两个数组的中位数 $m_1, m_2$  
    * 若 $m_1 = m_2$，直接返回  
    * 若 $m_1 < m_2$，则解在 Array1 右半部和 Array2 左半部  
    * 每次丢弃一半，递归求解  
* **复杂度**：$T(n) = T(n/2) + O(1) \Rightarrow O(\log n)$  

### 2. 寻找缺失的整数（0~100）  
* **方法1**：求和作差（$O(n)$）  
* **方法2**：异或运算（$O(n)$）  
* **方法3**：二分查找（如果有序，$O(\log n)$）  

### 3. 寻找出现奇数次的数  
* **思路**：利用异或性质 $x \oplus x = 0$  
* **方法**：所有元素异或一遍，结果即为所求  
* **复杂度**：$O(n)$

## 六、 分治法复习清单  

### 1. 计算能力  
* 给定递归式（如 $T(n)=3T(n/4)+n$），能快速用主定理算出复杂度  

### 2. 理论证明（重点）  
* **BFPRT**：为什么是 $O(n)$？（关键在于切分比例保证）  
* **最接近点对**：为什么只需检查6个点？（鸽巢原理）  

### 3. 代码逻辑  
* 归并排序的 **Merge** 过程  
* 快速排序的 **Partition** 过程  

### 4. 算法对比  
| 算法 | 时间复杂度 | 空间复杂度 | 特点 |  
| :--- | :--- | :--- | :--- |  
| **二分搜索** | $O(\log n)$ | $O(1)$ | 有序数组查找 |  
| **大整数乘法** | $O(n^{1.585})$ | $O(n)$ | 3次乘法优化 |  
| **Strassen** | $O(n^{2.81})$ | $O(n^2)$ | 7次乘法优化 |  
| **归并排序** | $O(n \log n)$ | $O(n)$ | 稳定、非就地 |  
| **快速排序** | 平均 $O(n \log n)$ | $O(\log n)$ | 不稳定、就地 |  
| **BFPRT** | $O(n)$ | $O(1)$ | 确定性选择 |  
| **最近点对** | $O(n \log n)$ | $O(n)$ | 鸽巢原理优化 |  

---  
**本章要点**：分治法通过“分而治之”将复杂问题分解，关键在于**分解策略**和**合并优化**。重点掌握主定理应用、排序算法对比，以及BFPRT和最近点对的理论证明。
