语法分析是编译过程的**核心**阶段。它在词法分析器生成的**记号（Token）序列**的基础上，根据源语言的**语法规则**（通常由上下文无关文法描述），检查记号序列是否在结构上构成了合法的程序（即“句子”），并构造出程序的层次结构，即**分析树**。  

### 1. 语法分析基础概念 (附录重点)  

在深入分析方法前，必须掌握以下基本概念：  

* **推导 (Derivation)**：从文法开始符号 $S$ 出发，应用产生式（如 $A \rightarrow \gamma$）将非终结符替换为其产生式右部的过程，记为 $\Rightarrow$。  
    * **最左推导 (Leftmost Derivation, $\Rightarrow_{lm}$)**：每一步推导都替换句型中**最左边**的非终结符。  
    * **最右推导 (Rightmost Derivation, $\Rightarrow_{rm}$)**：每一步推导都替换句型中**最右边**的非终结符。这也称为**规范推导**。  
* **句型、句子 (Sentential Form, Sentence)**：  
    * **句型**：从开始符号 $S$ 经过0步或多步推导得到的任何文法符号串 $\alpha$ ($S \Rightarrow^* \alpha$)。  
    * **句子**：一个**只包含终结符号**的句型。  
* **文法二义性 (Ambiguity)**：  
    * 如果一个文法可以为某个句子生成**多棵分析树**（或多个最左推导/最右推导），则该文法是**二义性**的。  
    * **示例1 (表达式)**：文法 `E → E+E | E*E | id` 对句子 `id+id*id` 有两棵分析树。  
    * **示例2 (悬挂else)**：文法 `stmt → if...then...stmt | if...then...stmt else...stmt` 对 `if E1 then if E2 then S1 else S2` 有二义性。这通常通过“`else` 与最近的 `then` 匹配”的规则来解决。  
* **短语、直接短语、句柄 (Phrase, Direct Phrase, Handle)**：  
    * 这些是自底向上分析的核心概念。  
    * **短语**：在句型 $\alpha\beta\delta$ 中，若 $S \Rightarrow^* \alpha A \delta$ 且 $A \Rightarrow^+ \beta$，则 $\beta$ 称为句型 $\alpha\beta\delta$ 相对于 $A$ 的短语。  
    * **直接短语**：如果 $A \Rightarrow \beta$（一步推导），则 $\beta$ 称为**直接短语**。  
    * **句柄**：一个句型的**最左直接短语**称为该句型的**句柄**。  

### 2. 语法分析的两大方法  

语法分析器主要分为两类，它们构造分析树的方向相反：  

1.  **自顶向下 (Top-Down)**：从根结点（开始符号）向叶结点（输入串）构造分析树。它试图为输入串找到一个**最左推导**。  
2.  **自底向上 (Bottom-Up)**：从叶结点（输入串）向根结点（开始符号）构造分析树。它实际上是**最右推导的逆过程**（称为规范归约）。  

### 3. 语法错误处理  

一个好的语法分析器必须能处理错误。  
* **目标**：清楚报告错误位置和性质、能从错误中恢复、且不影响正确程序的效率。  
* **紧急恢复 (Panic Mode)**：最简单的策略。一旦发现错误，分析器就**抛弃**输入记号，直到找到一个指定的**同步记号**（如 `;` 或 `end`）为止。

### 4. 自顶向下分析 (Top-Down Analysis)  

#### 4.1 递归下降分析 (Recursive Descent)  

* **思想**：为每个非终结符编写一个递归过程（函数）。  
* **试探性 (Backtracking)**：这是一种“试探性”的分析方法。当一个非终结符 $A$ 有多个候选产生式时（例如 $A \rightarrow \alpha_1 | \alpha_2 | \alpha_3$），分析器会**按顺序**尝试每一种可能：  
    1.  **试探**：分析器选择第一个产生式 $A \rightarrow \alpha_1$，并假设它是正确的。  
    2.  **匹配**：它尝试用 $\alpha_1$ 去匹配接下来的输入符号串。  
    3.  **成功**：如果 $\alpha_1$ 成功匹配了输入串的一部分，分析器就继续前进。  
    4.  **失败**：如果在匹配 $\alpha_1$ 的过程中发现不一致，分析器就必须**回溯 (Backtracking)**。  
* **回溯的代价**：  
    * 分析器将**输入指针**重置回尝试 $A \rightarrow \alpha_1$ 之前的原始位置。  
    * 它抛弃在尝试 $\alpha_1$ 期间所做的所有分析。  
    * 它返回到非终结符 $A$ 的地方，尝试下一个候选式 $A \rightarrow \alpha_2$。  
* **两大问题**：  
    1.  **左递归 (Left Recursion)**：产生式如 $A \rightarrow A\alpha$ 会导致递归函数无限调用，陷入死循环。  
    2.  **回溯 (Backtracking)**：重复工作多，效率极低，是一种穷尽一切可能的试探法。  

#### 4.2 文法改造 (Top-Down 的前提)  

为了实现高效的（无回溯的）自顶向下分析，必须改造文法：  

**1. 消除左递归**  
* **直接左递归**： $A \rightarrow A\alpha_1 | ... | A\alpha_m | \beta_1 | ... | \beta_n$  
* **消除方法**：替换为：  
    * $A \rightarrow \beta_1 A' | ... | \beta_n A'$  
    * $A' \rightarrow \alpha_1 A' | ... | \alpha_m A' | \epsilon$  
* **示例**：`E → E+T | T`  
    * 改写为：`E → TE'`  
    * `E' → +TE' | ε`  

**2. 提取左公因子**  
* **问题**： $A \rightarrow \alpha\beta_1 | \alpha\beta_2$。分析器看到 $\alpha$ 后，不知道该选择哪个产生式。  
* **提取方法**：替换为：  
    * $A \rightarrow \alpha A'$  
    * $A' \rightarrow \beta_1 | \beta_2$  
* **示例**：`stmt → if...then...stmt | if...then...stmt else...`  
    * 改写为：`stmt → if...then...stmt S'`  
    * `S' → else stmt | ε`  

#### 4.3 预测分析 (Predictive Analysis)  

这是一种**不带回溯**的递归下降分析。它能根据当前**向前看**的输入符号，**确切地**知道应选择哪个产生式。  

* **递归调用预测分析**：  
    * 为改造后（无左递归、无左公因子）的文法，每个非终结符编写一个递归过程。  
    * 函数内根据**当前输入符号**（`char`）来决定调用哪个其他过程或匹配哪个终结符。  
    * *示例*：`procE()` 先调用 `procT()`，然后检查是否有 `+`，如果有，就消耗 `+` 并再次调用 `procE()`（或 `procT()`，取决于消除左递归后的文法 `E' → +TE' | ε`）。  

* **非递归预测分析 (LL(1)分析法)**：  
    * 这是最重要的一种自顶向下方法。  
    * **LL(1) 含义**：**L** (Left-to-right scan) 从左到右扫描输入；**L** (Leftmost derivation) 构造最左推导；**1** (1 lookahead) 向前看1个记号。  
    * **模型**：由一个**输入缓冲区**、一个**符号栈**、一个**预测分析表M**和一个**控制程序**组成。  
    * **工作过程 (算法 4.1)**：  
        1.  $X$ = 栈顶符号；$a$ = 当前输入符号。  
        2.  **if ($X = a = \$$)**：**接受**，分析成功。  
        3.  **if ($X = a \neq \$$)**：**弹出 $X$**，输入指针 $ip$ 前移。  
        4.  **if ($X$ 是终结符但 $X \neq a$)**：**错误**。  
        5.  **if ($X$ 是非终结符)**：  
            * 查询 `M[X, a]`。  
            * **if ($M[X, a] = X \rightarrow Y_1Y_2...Y_k$)**：**弹出 $X$**，然后将 **$Y_k, ..., Y_2, Y_1$** (反序) 压入栈。输出该产生式。  
            * **if ($M[X, a]$ = 空白)**：**错误**。  

#### 4.4 构造 LL(1) 分析表  

构造 `M[A, a]` 的关键是计算 `FIRST` 和 `FOLLOW` 集合。  

**1. FIRST 集合**  
* **$FIRST(\alpha)$**：可以从 $\alpha$ 推导出的**开头终结符号**的集合。  
* **如果 $\alpha \Rightarrow^* \epsilon$** (能推导出空串)，则 $\epsilon \in FIRST(\alpha)$。  
* **计算规则**：  
    1.  若 $X$ 是终结符， $FIRST(X) = \{X\}$。  
    2.  若 $X \rightarrow \epsilon$，则 $\epsilon$ 加入 $FIRST(X)$。  
    3.  若 $X \rightarrow Y_1Y_2...Y_k$：  
        * 将 $FIRST(Y_1)$ (除 $\epsilon$ 外) 加入 $FIRST(X)$。  
        * 如果 $\epsilon \in FIRST(Y_1)$，则将 $FIRST(Y_2)$ (除 $\epsilon$ 外) 加入 $FIRST(X)$。  
        * ... 以此类推。如果所有 $FIRST(Y_i)$ 都含 $\epsilon$，则 $\epsilon$ 加入 $FIRST(X)$。  


##### 示例 1：简单情况（规则 1, 2, 3）  

考虑文法：  

$S \rightarrow A \text{ } c$  

$A \rightarrow b$  

$A \rightarrow \epsilon$  

1. **$FIRST(A)$**：  
   
    - 看 $A \rightarrow b$：根据规则 3，我们看 $FIRST(b)$。根据规则 1，$FIRST(b) = \{b\}$。我们将 $b$ 加入 $FIRST(A)$。  
        
    - 看 $A \rightarrow \epsilon$：根据规则 2，我们将 $\epsilon$ 加入 $FIRST(A)$。  
        
    - **结果：$FIRST(A) = \{ b, \epsilon \}$**  
        
2. **$FIRST(S)$**：  
    
    - 看 $S \rightarrow A \text{ } c$：根据规则 3，我们先看 $Y_1 = A$。  
        
    - 我们将 $FIRST(A) - \{\epsilon\}$ 加入 $FIRST(S)$。$FIRST(A)$ 是 $\{b, \epsilon\}$，所以我们加入 $b$。  
        
    - 现在 $FIRST(S) = \{b\}$。  
        
    - 规则 3 接着问：$\epsilon \in FIRST(A)$ 吗？是的。  
        
    - 因此，我们继续看 $Y_2 = c$。我们将 $FIRST(c) - \{\epsilon\}$ 加入 $FIRST(S)$。  
        
    - 根据规则 1，$FIRST(c) = \{c\}$。我们将 $c$ 加入 $FIRST(S)$。  
        
    - 现在 $FIRST(S) = \{ b, c \}$。  
        
    - 规则 3 接着问：$\epsilon \in FIRST(c)$ 吗？不是。  
        
    - 我们停止。  
        
    - **结果：$FIRST(S) = \{ b, c \}$**

考虑文法：  

$S \rightarrow A B C$  

$A \rightarrow a | \epsilon$  

$B \rightarrow b | \epsilon$  

$C \rightarrow c$

    - 看 $A \rightarrow a$：加入 $a$。  
        
    - 看 $A \rightarrow \epsilon$：根据规则 2，加入 $\epsilon$。  
        
    - **结果：$FIRST(A) = \{ a, \epsilon \}$**

    - 看 $S \rightarrow A B C$：根据规则 3，我们看 $Y_1 = A$。  
        
    - 我们将 $FIRST(A) - \{\epsilon\}$ 加入 $FIRST(S)$。加入 $a$。  
        
    - $FIRST(S) = \{a\}$。  
        
    - $\epsilon \in FIRST(A)$ 吗？是的。

    - $\epsilon \in FIRST(B)$ 吗？是的。  
        
    - 我们继续看 $Y_3 = C$。我们将 $FIRST(C) - \{\epsilon\}$ 加入 $FIRST(S)$。加入 $c$。  
        
    - $FIRST(S) = \{a, b, c\}$。  
        
    - $\epsilon \in FIRST(C)$ 吗？不是。  
        
    - 我们停止。  
        
    - **结果：$FIRST(S) = \{ a, b, c \}$**

    - 看 $B \rightarrow \epsilon$：根据规则 2，加入 $\epsilon$。  
        
    - **结果：$FIRST(B) = \{ \epsilon \}$**  
        
3. **$FIRST(S)$**：  
    
    - 看 $S \rightarrow A B$：根据规则 3，我们看 $Y_1 = A$。  
        
    - 我们将 $FIRST(A) - \{\epsilon\}$ 加入 $FIRST(S)$。（什么也没加入）。

**2. FOLLOW 集合**  
* **$FOLLOW(A)$**：在所有句型中，可能**紧跟在 $A$ 之后**出现的**终结符号**（或 `$`）的集合。  
* 如果 $A$ 可能是某个句型的最右符号，则 **\$** (输入结束符) $\in FOLLOW(A)$。  
* **计算规则**：  
    1.  将 **\$** 放入 $FOLLOW(S)$ (S是开始符号)。  
    2.  若有产生式 $A \rightarrow \alpha B \beta$，则 $FIRST(\beta)$ (除 $\epsilon$ 外) 加入 $FOLLOW(B)$。  
    3.  若有产生式 $A \rightarrow \alpha B$ **或** $A \rightarrow \alpha B \beta$ 且 $\beta \Rightarrow^* \epsilon$，则 $FOLLOW(A)$ 中的所有元素都加入 $FOLLOW(B)$。  
    4.  重复 2, 3 直到集合不再变化。  

### 示例 1：简单情况（规则 1, 2）  

文法：  

$S \rightarrow A \text{ } c$  

$A \rightarrow b$  

$A \rightarrow \epsilon$  

(开始符号是 $S$)  

FIRST 集 (已计算)：  

$FIRST(A) = \{ b, \epsilon \}$  

$FIRST(c) = \{ c \}$  

**计算 `FOLLOW` 集**：  

1. **初始化**：  
    
    - $FOLLOW(S) = \{ \$ \}$ (根据规则 1)  
        
    - $FOLLOW(A) = \{ \}$  
        
2. **第 1 轮迭代**：  
    
    - **分析产生式 $S \rightarrow A \text{ } c$**：  
        
        - 这符合规则 2 ($A \rightarrow \alpha B \beta$)，其中 $A=S$, $\alpha=\epsilon$, $B=A$, $\beta=c$。  
            
        - **应用规则 2**：将 $FIRST(c) - \{\epsilon\}$ 加入 $FOLLOW(A)$。  
            
        - $FIRST(c) = \{c\}$。因此，将 $c$ 加入 $FOLLOW(A)$。  
            
        - **应用规则 3**：检查 $\beta$ (即 $c$) 是否能推导出 $\epsilon$？$\epsilon \notin FIRST(c)$。因此规则 3 不适用于此。  
            
    - $FOLLOW(A)$ 变为 $\{ c \}$。  
        
3. **第 2 轮迭代**：  
    
    - 再次检查所有产生式，没有发现新的终结符可以被加入任何 `FOLLOW` 集合。  
        
4. **最终结果**：  
    
    - $FOLLOW(S) = \{ \$ \}$  
        
    - $FOLLOW(A) = \{ c \}$

### 示例 2：链式 nullable（规则 2, 3 结合）  

文法：  

$S \rightarrow A B C$  

$A \rightarrow a | \epsilon$  

$B \rightarrow b | \epsilon$  

$C \rightarrow c$  

(开始符号是 $S$)  

FIRST 集 (已计算)：  

$FIRST(A) = \{ a, \epsilon \}$  

$FIRST(B) = \{ b, \epsilon \}$  

$FIRST(C) = \{ c \}$  

**计算 `FOLLOW` 集**：  

1. **初始化**：  
    
    - $FOLLOW(S) = \{ \$ \}$ (规则 1)  
        
    - $FOLLOW(A) = \{ \}$  
        
    - $FOLLOW(B) = \{ \}$  
        
    - $FOLLOW(C) = \{ \}$  
        
2. **第 1 轮迭代**：  
    
    - **分析产生式 $S \rightarrow A B C$**：  
        
        - **对于 $A$** ($B=A, \beta=BC$)：  
            
            - **规则 2**：将 $FIRST(BC) - \{\epsilon\}$ 加入 $FOLLOW(A)$。  
                
            - $FIRST(BC) = (FIRST(B) - \{\epsilon\}) \cup (FIRST(C))$ (因为 $\epsilon \in FIRST(B)$)  
                
            - $FIRST(BC) = \{b\} \cup \{c\} = \{b, c\}$。  
                
            - 将 $\{b, c\}$ 加入 $FOLLOW(A)$。  
                
            - **规则 3**：$\epsilon \in FIRST(BC)$ 吗？不，因为 $\epsilon \notin FIRST(C)$。  
                
        - **对于 $B$** ($B=B, \beta=C$)：d  
            
            - **规则 2**：将 $FIRST(C) - \{\epsilon\}$ 加入 $FOLLOW(B)$。  
                
            - $FIRST(C) = \{c\}$。将 $c$ 加入 $FOLLOW(B)$。  
                
            - **规则 3**：$\epsilon \in FIRST(C)$ 吗？不。  
                
        - **对于 $C$** ($B=C, \beta=\epsilon$，即 $A \rightarrow \alpha B$ 形式)：  
            
            - **规则 3**：将 $FOLLOW(S)$ 加入 $FOLLOW(C)$。  
                
            - $FOLLOW(S) = \{\$\}$。将 $\$$ 加入 $FOLLOW(C)$。  
                
3. **第 2 轮迭代**：  
    
    - 没有新符号加入。  
        
4. **最终结果**：  
    
    - $FOLLOW(S) = \{ \$ \}$  
        
    - $FOLLOW(A) = \{ b, c \}$  
        
    - $FOLLOW(B) = \{ c \}$  
        
    - $FOLLOW(C) = \{ \$ \}$

### 示例 4：递归文法（表达式文法）  

这是最典型、最重要的例子，它需要多次迭代才能稳定。  

文法：  

$E \rightarrow T E'$  

$E' \rightarrow + T E' | \epsilon$  

$T \rightarrow F T'$  

$T' \rightarrow * F T' | \epsilon$  

$F \rightarrow ( E ) | \text{id}$  

(开始符号是 $E$)  

FIRST 集 (已计算)：  

$FIRST(E) = \{ (, \text{id} \}$  

$FIRST(E') = \{ +, \epsilon \}$  

$FIRST(T) = \{ (, \text{id} \}$  

$FIRST(T') = \{ *, \epsilon \}$  

$FIRST(F) = \{ (, \text{id} \}$  

**计算 `FOLLOW` 集**：  

1. **初始化**：  
    
    - $FOLLOW(E) = \{ \$ \}$ (规则 1)  
        
    - $FOLLOW(E') = \{ \}$  
        
    - $FOLLOW(T) = \{ \}$  
        
    - $FOLLOW(T') = \{ \}$  
        
    - $FOLLOW(F) = \{ \}$  
        
2. **第 1 轮迭代**：  
    
    - **$E \rightarrow T E'$**:  
        
        - **对于 $T$** ($\beta=E'$):  
            
            - 规则 2：将 $FIRST(E') - \{\epsilon\} = \{+\}$ 加入 $FOLLOW(T)$。  
                
            - 规则 3：因为 $\epsilon \in FIRST(E')$，将 $FOLLOW(E)$ 加入 $FOLLOW(T)$。  
                
            - $FOLLOW(T)$ 变为 $\{ +, \$ \}$。  
                
        - **对于 $E'$** ($\beta=\epsilon$):  
            
            - 规则 3：将 $FOLLOW(E)$ 加入 $FOLLOW(E')$。  
                
            - $FOLLOW(E')$ 变为 $\{ \$ \}$。  
                
    - **$E' \rightarrow + T E'$**:  
        
        - **对于 $T$** ($\beta=E'$):  
            
            - 规则 2：将 $FIRST(E') - \{\epsilon\} = \{+\}$ 加入 $FOLLOW(T)$ (已存在)。  
                
            - 规则 3：因为 $\epsilon \in FIRST(E')$，将 $FOLLOW(E')$ 加入 $FOLLOW(T)$。  
                
            - $FOLLOW(E') = \{\$\}$。将 $\$$ 加入 $FOLLOW(T)$ (已存在)。  
                
    - **$T \rightarrow F T'$**:  
        
        - **对于 $F$** ($\beta=T'$):  
            
            - 规则 2：将 $FIRST(T') - \{\epsilon\} = \{*\}$ 加入 $FOLLOW(F)$。  
                
            - 规则 3：因为 $\epsilon \in FIRST(T')$，将 $FOLLOW(T)$ 加入 $FOLLOW(F)$。  
                
            - $FOLLOW(T) = \{ +, \$ \}$。  
                
            - $FOLLOW(F)$ 变为 $\{ *, +, \$ \}$。  
                
        - **对于 $T'$** ($\beta=\epsilon$):  
            
            - 规则 3：将 $FOLLOW(T)$ 加入 $FOLLOW(T')$。  
                
            - $FOLLOW(T') = \{ +, \$ \}$。  
                
    - **$T' \rightarrow * F T'$**:  
        
        - **对于 $F$** ($\beta=T'$):  
            
            - 规则 2：将 $FIRST(T') - \{\epsilon\} = \{*\}$ 加入 $FOLLOW(F)$ (已存在)。  
                
            - 规则 3：因为 $\epsilon \in FIRST(T')$，将 $FOLLOW(T')$ 加入 $FOLLOW(F)$。  
                
            - $FOLLOW(T') = \{ +, \$ \}$。将 $\{ +, \$ \}$ 加入 $FOLLOW(F)$ (已存在)。  
                
    - **$F \rightarrow ( E )$**:  
        
        - **对于 $E$** ($\beta= \text{')'}$ ):  
            
            - 规则 2：将 $FIRST(\text{')'}) - \{\epsilon\} = \{ ) \}$ 加入 $FOLLOW(E)$。  
                
            - $FOLLOW(E)$ 变为 $\{ \$, ) \}$。  
                
    - **（此时集合为）**：  
        
        - $FOLLOW(E) = \{ \$, ) \}$  
            
        - $FOLLOW(E') = \{ \$ \}$  
            
        - $FOLLOW(T) = \{ +, \$ \}$  
            
        - $FOLLOW(T') = \{ +, \$ \}$  
            
        - $FOLLOW(F) = \{ *, +, \$ \}$  
            
3. **第 2 轮迭代** (集合发生了变化，必须重新迭代)：  
    
    - **$E \rightarrow T E'$**:  
        
        - **对于 $T$** ($\beta=E'$):  
            
            - 规则 3：将 $FOLLOW(E)$ 加入 $FOLLOW(T)$。  
                
            - $FOLLOW(E) = \{ \$, ) \}$。将 `)` 加入 $FOLLOW(T)$ (新)。  
                
            - $FOLLOW(T)$ 变为 $\{ +, \$, ) \}$。  
                
        - **对于 $E'$** ($\beta=\epsilon$):  
            
            - 规则 3：将 $FOLLOW(E)$ 加入 $FOLLOW(E')$。  
                
            - $FOLLOW(E) = \{ \$, ) \}$。将 `)` 加入 $FOLLOW(E')$ (新)。  
                
            - $FOLLOW(E')$ 变为 $\{ \$, ) \}$。  
                
    - **$E' \rightarrow + T E'$**:  
        
        - **对于 $T$** ($\beta=E'$):  
            
            - 规则 3：将 $FOLLOW(E')$ 加入 $FOLLOW(T)$。  
                
            - $FOLLOW(E') = \{ \$, ) \}$ (这是新值)。将 `)` 加入 $FOLLOW(T)$ (已存在)。  
                
    - **$T \rightarrow F T'$**:  
        
        - **对于 $F$** ($\beta=T'$):  
            
            - 规则 3：将 $FOLLOW(T)$ 加入 $FOLLOW(F)$。  
                
            - $FOLLOW(T) = \{ +, \$, ) \}$ (这是新值)。将 `)` 加入 $FOLLOW(F)$ (新)。  
                
            - $FOLLOW(F)$ 变为 $\{ *, +, \$, ) \}$。  
                
        - **对于 $T'$** ($\beta=\epsilon$):  
            
            - 规则 3：将 $FOLLOW(T)$ 加入 $FOLLOW(T')$。  
                
            - $FOLLOW(T) = \{ +, \$, ) \}$ (这是新值)。将 `)` 加入 $FOLLOW(T')$ (新)。  
                
            - $FOLLOW(T')$ 变为 $\{ +, \$, ) \}$。  
                
    - **$T' \rightarrow * F T'$**:  
        
        - **对于 $F$** ($\beta=T'$):  
            
            - 规则 3：将 $FOLLOW(T')$ 加入 $FOLLOW(F)$。  
                
            - $FOLLOW(T') = \{ +, \$, ) \}$ (这是新值)。将 `)` 加入 $FOLLOW(F)$ (已存在)。  
                
4. **第 3 轮迭代**：  
    
    - 再次检查所有产生式，没有发现新的终结符可以被加入任何 `FOLLOW` 集合。集合已稳定。  
        
5. **最终结果**：  
    
    - $FOLLOW(E) = \{ \$, ) \}$  
        
    - $FOLLOW(E') = \{ \$, ) \}$  
        
    - $FOLLOW(T) = \{ +, \$, ) \}$  
        
    - $FOLLOW(T') = \{ +, \$, ) \}$  
        
    - $FOLLOW(F) = \{ *, +, \$, ) \}$  


**3. 构造分析表 (算法 4.2)**  
* 对文法 G 的**每个**产生式 $A \rightarrow \alpha$ 执行：  
    1.  **For** ( $FIRST(\alpha)$ 中的每个终结符 $a$ )  
        * **$M[A, a] = A \rightarrow \alpha$**。  
    2.  **If** ( $\epsilon \in FIRST(\alpha)$ )  
        * **For** ( $FOLLOW(A)$ 中的每个终结符 $b$ 或 \$ )  
            * **$M[A, b] = A \rightarrow \alpha$**。  
* 所有其他 $M[A, a]$ 均填 "error"。  

**LL(1) 文法**：如果构造的分析表 $M$ **不含多重定义的表项**（即没有冲突），则该文法是 $LL(1)$ 文法。  

#### 4.5 详细示例：LL(1) 分析的全过程  

让我们以一个表达式文法为例，完整地走一遍 LL(1) 的所有步骤。  

**目标**：为文法 $G$ 构造一个 LL(1) 分析器，并分析输入串 `num * num $`。  
**原始文法 G**：  
$E \rightarrow E+T | E-T | T$  
$T \rightarrow T*F | T/F | F$  
$F \rightarrow (E) | \text{num}$  

**第1步：检查 LL(1) 条件并改写文法**  

* **检查**：原始文法 G **不是 LL(1) 文法**。  
    * $E$ 的产生式 $E \rightarrow E+T$ 和 $E \rightarrow T$ 存在**左递归**。  
    * $E' \rightarrow +TE' | -TE'$ 存在**左公因子**（虽然在此例中，消除左递归已顺带解决）。  
    * LL(1) 文法要求对于 $A \rightarrow \alpha | \beta$，必须满足 $FIRST(\alpha) \cap FIRST(\beta) = \emptyset$。原始文法不满足。  

* **改写文法 G $\rightarrow$ G'（消除左递归）**：  
    * 对于 E：  
        $E \rightarrow TE'$  
        $E' \rightarrow +TE' | -TE' | \epsilon$  
    * 对于 T：  
        $T \rightarrow FT'$  
        $T' \rightarrow *FT' | /FT' | \epsilon$  
    * 对于 F： (无变化)  
        $F \rightarrow (E) | \text{num}$  

* **最终文法 G'**：  
    (0) $E \rightarrow TE'$  
    (1) $E' \rightarrow +TE'$  
    (2) $E' \rightarrow -TE'$  
    (3) $E' \rightarrow \epsilon$  
    (4) $T \rightarrow FT'$  
    (5) $T' \rightarrow *FT'$  
    (6) $T' \rightarrow /FT'$  
    (7) $T' \rightarrow \epsilon$  
    (8) $F \rightarrow (E)$  
    (9) $F \rightarrow \text{num}$  

**第2步：计算 FIRST 和 FOLLOW 集**  

* **FIRST 集**：  
    * $FIRST(F) = \{ (, \text{num} \}$  
    * $FIRST(T') = \{ *, /, \epsilon \}$  
    * $FIRST(T) = FIRST(F) = \{ (, \text{num} \}$  
    * $FIRST(E') = \{ +, -, \epsilon \}$  
    * $FIRST(E) = FIRST(T) = \{ (, \text{num} \}$  

* **FOLLOW 集**：  
    * $FOLLOW(E) = \{ \$, ) \}$ ( `$` 是开始符号, `)` 来自 $F \rightarrow (E)$)  
    * $FOLLOW(E') = FOLLOW(E) = \{ \$, ) \}$ (来自 $E \rightarrow TE'$)  
    * $FOLLOW(T) = (FIRST(E') - \{\epsilon\}) \cup FOLLOW(E') = \{+, -\} \cup \{ \$, ) \} = \{ +, -, \$, ) \}$  
    * $FOLLOW(T') = FOLLOW(T) = \{ +, -, \$, ) \}$ (来自 $T \rightarrow FT'$)  
    * $FOLLOW(F) = (FIRST(T') - \{\epsilon\}) \cup FOLLOW(T') = \{*, /\} \cup \{ +, -, \$, ) \} = \{ *, /, +, -, \$, ) \}$  
- 根据公式计算SELECT集  
$$\mathrm{SELECT}(\mathrm{A}\to\alpha)=  
\begin{cases}  
First(\alpha), & \quad\alpha\overset{*}{\operatorname*{\neq}}\varepsilon \\  
(First(\alpha)-\{\varepsilon\})\cup FOLLOW(A), & \quad\alpha\overset{*}{\operatorname*{\Rightarrow}}\varepsilon &  
\end{cases}$$  

**第3步：构造预测分析表 M**  

| | **num** | **+** | **-** | **\*** | **/** | **(** | **)** | **$** |  
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |

### 5. 自底向上分析 (Bottom-Up Analysis)  

#### 5.1 “移进-归约”分析 (Shift-Reduce)  

这是自底向上分析的通用方法。它使用一个**符号栈**。  
* **核心**：在分析过程中，栈顶的符号串始终是规范句型的一个**活前缀 (Viable Prefix)**。  
* **活前缀**：一个规范句型（最右推导得到的句型）的前缀，且**不包含句柄之后的任何符号**。  
* **四种动作**：  
    1.  **移进 (Shift)**：将下一个输入符号压入栈顶。  
    2.  **归约 (Reduce)**：当栈顶形成一个**句柄** $\beta$ 时，用产生式 $A \rightarrow \beta$ 将其归约。即，从栈顶弹出 $\beta$，再将 $A$ 压入栈。  
    3.  **接受 (Accept)**：当栈中只剩开始符号 $S$ 且输入结束时，分析成功。  
    4.  **错误 (Error)**：无法执行上述动作。  
* **冲突**：该方法的难点在于如何**准确找到句柄**并决定何时移进、何时归约。  
    * **移进-归约冲突 (Shift-Reduce Conflict)**  
    * **归约-归约冲突 (Reduce-Reduce Conflict)**  

#### 5.2 LR 分析法  

LR分析法是目前最强大、最高效的自底向上分析技术，它能**确定性地**解决移进-归约冲突。  

* **LR(k) 含义**：**L** (Left-to-right scan) 从左到右扫描，**R** (Rightmost derivation) 构造最右推导的逆过程，**k** (k个向前看符号)。  
* **LR 分析模型**：  
    * 一个**栈**，但栈中存放的是**状态 (state)** $S_m$ 和文法符号 $X_m$。栈顶状态 $S_m$ 隐含了已识别的活前缀信息。  
    * 一个**LR分析表**，分为两部分：  
        * **ACTION\[状态, 终结符]**：指定 (shift, reduce, accept, error)。  
        * **GOTO\[状态, 非终结符]**：指定归约后要转移到的**新状态**。  
* **工作过程 (算法 4.3)**：  
    1.  $S$ = 栈顶状态；$a$ = 当前输入。  
    2.  **if (ACTION\[S, a] = Shift $S'$)**：将 $S'$ 压入栈， $ip$ 前移。  
    3.  **if (ACTION\[S, a] = Reduce $A \rightarrow \beta$)** (假设 $|\beta|=r$)：  
        * 从栈顶弹出 $r$ 个状态（和符号）。  
        * $S'$ = 此时的栈顶状态。  
        * $S''$ = **GOTO\[S', A]**。  
        * 将 $S''$ 压入栈。  
    4.  **if (ACTION\[S, a] = Accept)**：分析成功。  
    5.  **if (ACTION\[S, a] = Error)**：调用错误处理。  

#### 5.3 构造 LR 分析表  

构造LR分析表的核心是构造一个**识别文法所有活前缀的DFA**。DFA的每个状态就是一个**LR项目集**。  

* **拓广文法 (Augmented Grammar)**：在原文法G中加入一个新产生式 $S' \rightarrow S$，其中 $S'$ 是新的开始符号。这用于产生唯一的“接受”状态。  
* **LR(0) 项目**：一个文法产生式，其右部某位置加了一个**圆点 `•`**。  
    * $A \rightarrow \bullet XYZ$ (待约项目，期待 $X$)  
    * $A \rightarrow X \bullet YZ$ (移进项目，已看到 $X$，期待 $Y$)  
    * $A \rightarrow XYZ \bullet$ (归约项目，已看到 $XYZ$，准备归约)  
* **核心操作1：`closure(I)` (闭包)** (算法 4.4)  
    * **思想**：如果一个项目 $A \rightarrow \alpha \bullet B \beta$ 在项目集 $I$ 中（意味着我们正在期待 $B$），那么 $B$ 的所有产生式（如 $B \rightarrow \bullet \eta$）也必须被加入到 $I$ 中，因为我们 *也* 在期待 $\eta$。  
    * 重复此过程直到 $I$ 不再增大。  
* **核心操作2：`go(I, X)` (转移函数)**  
    * **思想**：`go(I, X)` 模拟DFA在读入符号 $X$ 后的状态转移。  
    * `go(I, X)` = `closure( {` 所有 $A \rightarrow \alpha X \bullet \beta$ 这样的项目 | $A \rightarrow \alpha \bullet X \beta$ 在 $I$ 中 `} )`。  
* **DFA 构造 (LR(0)项目集规范族)** (算法 4.5)  
    1.  初态 $I_0 = closure( \{ S' \rightarrow \bullet S \} )$。  
    2.  `C = { I_0 }`。  
    3.  循环：对 $C$ 中每个 $I_i$ 和每个文法符号 $X$，计算 $I_j = go(I_i, X)$。如果 $I_j$ 不为空且不在 $C$ 中，将其加入 $C$。  
    4.  DFA的**状态**就是 $I_0, I_1, ...$。  

LR分析表的本质：构造识别活前缀的NFA之后，将NFA转化为DFA得到的结果。这里省略了NFA-DFA的转化，通过一个特殊的算法，可以直接省略掉这一步。将构造子集，计算闭包的过程直接纳入算法。  

---  

#### 5.4 三种 LR 分析表  

**1. SLR(1) (Simple LR)**  
* 使用 **LR(0) 项目集** 和 **FOLLOW 集** 来构造。  
* **SLR(1) 表构造 (算法 4.6)**：  
    * **ACTION - Shift**：如果 $A \rightarrow \alpha \bullet a \beta \in I_i$ ( $a$ 是终结符) 且 $go(I_i, a) = I_j$，则 `ACTION[i, a] = Shift j`。  
    * **ACTION - Reduce**：如果 $A \rightarrow \alpha \bullet \in I_i$ (归约项目)：  
        * **For** ( $FOLLOW(A)$ 中的所有终结符 $a$ )  
        * **`ACTION[i, a] = Reduce A \rightarrow \alpha`**。  
    * **ACTION - Accept**：如果 $S' \rightarrow S \bullet \in I_i$，则 `ACTION[i, $] = Accept`。  
    * **GOTO**：如果 $go(I_i, A) = I_j$ ( $A$ 是非终结符)，则 `GOTO[i, A] = j`。  
* **冲突**：如果 $I_i$ 中同时有 $A \rightarrow \alpha \bullet a \beta$ 和 $B \rightarrow \gamma \bullet$，且 $a \in FOLLOW(B)$，则 `ACTION[i, a]` 既是 `Shift` 又是 `Reduce`，产生**移进-归约冲突**。  

**2. LR(1) (Canonical LR)**  
* SLR(1) 的 $FOLLOW$ 集过于宽泛，导致不必要的冲突。LR(1) 通过在项目中携带**向前看符号 (lookahead)** 来精确化归约时机。  
* **LR(1) 项目**：形式为 $[A \rightarrow \alpha \bullet \beta, a]$，其中 $a$ 是终结符（向前看符号）。  
    * $[A \rightarrow \alpha \bullet, a]$ 意味着：**仅当**下一个输入符号是 $a$ 时，才按 $A \rightarrow \alpha$ 归约。  
* **`closure(I)` (算法 4.7)**：  
    * 如果 $[A \rightarrow \alpha \bullet B \beta, a] \in I$，则对 **$FIRST(\beta a)$** 中的每个符号 $b$，将 $[B \rightarrow \bullet \eta, b]$ 加入 $I$。  
* **LR(1) 表构造 (算法 4.9)**：  
    * **ACTION - Shift**：如果 $[A \rightarrow \alpha \bullet a \beta, b] \in I_i$ 且 $go(I_i, a) = I_j$，则 `ACTION[i, a] = Shift j`。  
    * **ACTION - Reduce**：如果 $[A \rightarrow \alpha \bullet, a] \in I_i$ ( $A \ne S'$ )：  
        * **`ACTION[i, a] = Reduce A \rightarrow \alpha`**。 (注意：只在 $a$ 这一列填入，不再使用 $FOLLOW$ 集)。  
* **优点**：最强大的分析方法。  
* **缺点**：状态集（DFA）非常庞大，分析表可能非常大。  

**3. LALR(1) (Look-Ahead LR)**  
* 一种**折中**方案：状态数与 SLR(1) 相同，分析能力接近 LR(1)。  
* **构造思想** (算法 4.10)：  
    1.  先构造出完整的 **LR(1) 项目集规范族**。  
    2.  找出所有**同心集 (core)** 并**合并**它们。  
        * **同心集**：指 $LR(1)$ 项目集中，忽略“向前看符号”后，其 $LR(0)$ 项目部分完全相同的集合。  
        * *示例*：$I_3 = \{[C \rightarrow c \bullet C, c/d], ... \}$ 和 $I_6 = \{[C \rightarrow c \bullet C, \$], ... \}$ 是同心集，合并为 $I_{36} = \{[C \rightarrow c \bullet C, c/d/\$], ... \}$。  
    3.  根据合并后的新项目集 $C'$ 构造分析表。  
* **冲突**：合并同心集**不会**产生新的“移进-归约”冲突，但**可能**会产生“归约-归约”冲突。  

---  

### 6. 文法层级总结  

PPT 第94页总结了各类文法的关系：  
* **LR(0) $\subset$ SLR(1) $\subset$ LALR(1) $\subset$ LR(1)**  
* **LL(1) $\subset$ LALR(1)**  
* 所有这些都是**无二义性文法**的子集。
